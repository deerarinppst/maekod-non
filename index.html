พืช
แม่กด (ไม่ตรงมาตรา)

คำนี้มีคำอ่านสะกดคำที่ถูกต้องอย่างไร?

ด่านเขียนสะกดคำด้วยนิ้วหรือปากกา
จงเขียนสะกดคำของคำว่า: พืช (เช่น พอ-อือ-ชอ=พืช)
✍️ ใช้นิ้วมือหรือปากกาเขียนลงบนนี้ได้ทันที
ด่านเรียงบล็อกเสียงสะกด
เรียงการสะกดคำแม่กดของคำว่า: รถ
แตะบล็อกด้านล่างเพื่อเรียงต่อกัน:
คลังบล็อกพยัญชนะ สระ และตัวสะกด:
✨
ถูกต้อง ยอดเยี่ยม!

⭐ พยัญชนะตัวสะกดแม่กด

จ ช ซ ฎ ฏ ฐ ฑ ฒ ต ถ ท ธ ศ ษ ส

📝 ตัวอย่างการสะกดคำ

  • • พืช = พอ - อือ - ชอ = พืช
  • • รถ = รอ - โอะ - ถอ = รถ
  • • โทษ = ทอ - โอ - ษอ = โทษ
  • • พุธ = พอ - อุ - ธอ = พุธ
  • • มงกุฎ = กอ - อุ - ฎอ = กุฎ
